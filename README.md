All-in-one file for a web interface that shows tilt, acceleration, rotation speed.

FEATURES :
Tilt meter.
Wheelchair preview.
Detects the state of the wheelchair (Normal, tilt forward/backward, tilt sideways, fallen forward/backward, fallen sideways)
A fall is detected when it is tilted over 45° in either direction for over 2 seconds.
The fall can be either a fasle alarm or a critical fall (less than 10 second is a false alarm, over that is critical).
