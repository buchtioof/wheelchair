# wheelchair

The GPS tracker code is based on [this project](https://github.com/johannajes/GPS_ESP32/tree/main)

This branch is dedicated to the GPS tracker as part of a study project aimed at creating a fully connected system using an ESP32.

The project includes a GPS tracker (this one), fall detection, temperature monitoring, and more…

To complement the code in this branch, another Git repository containing the ReactJS website that retrieves GPS data is [available here](https://github.com/buchtioof/wheelchair_web)
